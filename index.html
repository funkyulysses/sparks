About Spark

Spark is a quick-capture journal that lives entirely in this browser. Notes, tags, and pins are stored only in this device's local storage — nothing is sent anywhere, and there's no account. Use Export regularly to keep a backup file.

Type #tag to label a note, **bold** for emphasis, and `code` for a code span — links are detected automatically. Reply to a note to start a thread.
